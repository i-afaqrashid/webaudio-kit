# webaudio-kit Design References

This folder keeps static references for the public web surface. The production
site lives in `apps/site`; these files are lightweight review artifacts for
landing page composition, docs page copy, icon treatment, and social previews.

## Files

- `landing.html`: static version of the home page direction.
- `docs-overview.html`: static version of the documentation direction.
- `assets/styles.css`: shared design reference CSS.
- `assets/icon.svg`: simple package mark used by the static references.
- `assets/social-preview.html`: social preview frame for screenshots.

## Brand notes

- Keep the product practical and technical, not medical.
- Lead with real demo proof: tone controls, sweep controls, waveform output.
- Keep warnings direct: this is browser audio prototype software, not certified
  audiology software.
