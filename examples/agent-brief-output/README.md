# Agent brief output

This directory shows the kind of file generated by:

```sh
pnpm dlx @webaudio-kit/cli agent-brief --target codex --out AGENTS.md
```

Use it as a reference when asking coding agents to add webaudio-kit to an app.
The generated brief points agents to the public docs, package pages, examples,
browser autoplay constraints, safe gain defaults, and the project scope boundary
before they edit code.
