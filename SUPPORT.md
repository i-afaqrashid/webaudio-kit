# Support

## Where To Ask

- Bugs: open a GitHub issue with a minimal reproduction.
- Feature requests: open a GitHub issue and describe the browser audio use case.
- Security issues: follow `SECURITY.md`.

## What To Include

- Browser and version.
- Operating system.
- Package versions.
- Minimal React example.
- Whether the issue happens after a user gesture such as a button click.

## Scope

`webaudio-kit` supports browser audio interfaces and prototypes. It does not
provide medical, audiology, calibration, diagnosis, or hearing-test support.
